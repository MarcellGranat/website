# Hand-written site layer

- `index.html` (repo root) + `home/` : homepage, plain HTML/CSS/JS (not rendered by Quarto).
- `blog.html`, `about.html`, and every `posts/<id>/index.html` in `_site/` are generated by
  `home/scripts/build-pages.mjs`, which takes the post body from a Quarto render and wraps it in the site template.

## Update a post
1. Render the project into a scratch copy (never a full render inside this repo: it would wipe the
   non-Quarto folders in `_site/`, e.g. `bigdata/`):
   `rsync -a --exclude _site --exclude .git --exclude website-with-js ./ /tmp/proj/ && (cd /tmp/proj && quarto render)`
2. `node home/scripts/build-posts.mjs` (refresh `home/data/posts.js`)
3. `node home/scripts/build-pages.mjs /tmp/proj/_site _site`
4. `rsync -a --exclude scripts home/ _site/home/` and copy `index.html` to `_site/`.
